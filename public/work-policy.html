🚀 Team Work Policy & Code of Conduct

นโยบายและระเบียบการร่วมทีม BestCyniX Dev

ฉบับปรับปรุงล่าสุด: สิงหาคม 2569 • เอกสารสำหรับสมาชิกทีมและผู้สมัครทุกคน

1. วัตถุประสงค์และวิสัยทัศน์ (Vision & Mission)

BestCyniX Dev เป็นกลุ่มนักพัฒนาอิสระและคอมมูนิตี้ที่มุ่งเน้นการสร้างสรรค์นวัตกรรมซอฟต์แวร์ บอท Discord (เช่น SkyLineBOT), เว็บแอปพลิเคชัน และระบบคลาวด์ เพื่อมอบคุณค่าและประสบการณ์ที่ดีที่สุดแก่ผู้ใช้งาน การร่วมทีมของเรามุ่งเน้นการเรียนรู้ การทำงานร่วมกันด้วยความเคารพ และการรักษามาตรฐานระดับมืออาชีพ

2. จรรยาบรรณและมาตรฐานการทำงาน (Code of Conduct)

  • ความซื่อสัตย์สุจริต: สมาชิกทีมต้องปฏิบัติหน้าที่ด้วยความโปร่งใส ไม่แสวงหาผลประโยชน์ส่วนตนโดยมิชอบจากทรัพย์สิน ข้อมูล หรือบอทของทีม
  • การให้เกียรติและเคารพซึ่งกันและกัน: ไม่อนุญาตให้มีการกลั่นแกล้ง (Bullying), การใช้คำพูดหยาบคาย หรือการเหยียดเชื้อชาติ ศาสนา เพศสภาพ ในคอมมูนิตี้และช่องทางการทำงาน
  • ความรับผิดชอบต่องาน: ส่งมอบงานตามกรอบเวลาที่ตกลงกัน หากติดภารกิจการเรียนหรืองานส่วนตัว ต้องแจ้งหัวหน้าทีมหรือเพื่อนร่วมทีมล่วงหน้า
  • การติดต่อสื่อสาร: ใช้ช่องทาง Discord, GitHub หรือการประชุมทีมที่กำหนดในการประสานงานเพื่อความชัดเจนและสามารถตรวจสอบได้

3. การรักษาความลับและทรัพย์สินทางปัญญา (NDA & IP Policy)

ข้อกำหนดสำคัญ: สมาชิกทุกคนต้องรักษาความลับของโปรเจกต์ โค้ดต้นฉบับ (Source Code), API Keys, ฐานข้อมูล และข้อมูลส่วนบุคคลของผู้ใช้งาน ห้ามเผยแพร่หรือนำไปใช้ส่วนตัวโดยไม่ได้รับความยินยอมเป็นลายลักษณ์อักษรจาก BestCyniX Dev

  • โค้ด กราฟิก และเอกสารที่สร้างขึ้นภายใต้โปรเจกต์ของ BestCyniX Dev ถือเป็นทรัพย์สินร่วมของทีม
  • ห้ามดาวน์โหลด ดัดแปลง หรือแจกจ่ายฐานข้อมูลสมาชิกหรือ Token ระบบโดยเด็ดขาด

4. สิทธิประโยชน์และการพัฒนาทักษะ (Team Benefits)

  • โอกาสเข้าร่วมโปรเจกต์จริงที่รองรับผู้ใช้งานหลักหมื่นคน
  • ยศและบทบาทพิเศษใน Discord Server พร้อมการเข้าถึงห้อง Dev Room เฉพาะกิจ
  • การรับหนังสือรับรองการทำงาน / หนังสือรับรองการฝึกงาน (Certificate of Contribution)
  • ส่วนแบ่งค่าตอบแทนหรือรางวัลตามที่ตกลงกันในแต่ละโปรเจกต์ที่สร้างรายได้

5. การสิ้นสุดการร่วมทีม (Offboarding)

การร่วมทีมอาจสิ้นสุดลงในกรณี:

  • สมาชิกขอยุติบทบาทด้วยตนเอง (แจ้งล่วงหน้าอย่างน้อย 14 วันเพื่อส่งต่องาน)
  • การละเมิดกฎระเบียบ จรรยาบรรณ หรือการกระทำที่ก่อให้เกิดความเสียหายร้ายแรงต่อระบบและชื่อเสียงของทีม
